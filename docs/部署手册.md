# 部署手册

## 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | CentOS 7+ / Rocky 8+ / Ubuntu 20.04+ |
| CPU | 2 核及以上 |
| 内存 | 4 GB 及以上 |
| 磁盘 | 20 GB 及以上 |
| 网络 | 需开放 22（SSH）、80（HTTP）、443（HTTPS）端口 |

## 部署步骤

### 第一步：初始化服务器

```bash
# 1. 将代码上传到服务器
scp -r server-deploy-toolkit ops@目标IP:/opt/

# 2. SSH 登录服务器
ssh ops@目标IP

# 3. 执行初始化
cd /opt/server-deploy-toolkit
sudo bash init_server.sh
```

脚本自动完成：
- 检测系统类型（CentOS/Ubuntu）
- 安装 vim、curl、git、htop 等基础工具
- 关闭 SELinux（CentOS）
- 开放防火墙 22/80/443 端口
- 创建 ops 运维账号 + 免密切 sudo
- 设置时区 Asia/Shanghai
- 调优系统参数

### 第二步：安装 Docker

```bash
# CentOS
sudo yum install -y docker docker-compose-plugin
sudo systemctl start docker
sudo systemctl enable docker

# Ubuntu
sudo apt install -y docker.io docker-compose-v2
sudo systemctl start docker
sudo systemctl enable docker
```

### 第三步：部署 LNMP 环境

```bash
cd /opt/server-deploy-toolkit

# 启动所有服务
sudo docker compose up -d

# 查看状态
sudo docker compose ps
```

### 第四步：部署应用

```bash
# 将应用打包上传后执行
sudo bash deploy.sh --app=myapp --version=1.0.0
```

## 验证清单

| 验证项 | 命令 | 预期结果 |
|--------|------|---------|
| Nginx 运行 | `docker compose ps nginx` | `Status: Up (healthy)` |
| MySQL 运行 | `docker compose exec mysql mysqladmin ping -u root -p` | `mysqld is alive` |
| Redis 运行 | `docker compose exec redis redis-cli ping` | `PONG` |
| PHP-FPM 运行 | `docker compose ps php` | `Status: Up (healthy)` |
| 健康检查 | `python health_check.py` | 全部 ✅ |
| Web 访问 | `curl http://localhost/health` | `OK` |

## 常见故障排查

### Nginx 无法启动

```bash
docker compose logs nginx            # 查看日志
docker compose exec nginx nginx -t   # 检查配置语法
```

### MySQL 连接被拒

```bash
# 检查端口是否绑定
netstat -tlnp | grep 3306

# 确认密码正确
docker compose exec mysql mysql -u root -p
```

### 某个容器反复重启

```bash
docker compose logs --tail=50 <服务名>    # 查看最后 50 行日志
docker compose down                       # 完全停止
docker compose up -d                      # 重新启动
```

### 防火墙导致端口不通

```bash
# CentOS
firewall-cmd --list-ports

# Ubuntu
ufw status
```
